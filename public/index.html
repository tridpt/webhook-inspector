Nắm trọn cách bắt gói tin Webhook, mở Public Tunnel 1-click, dò API bằng trình duyệt ngầm (Headless Chrome/Edge), giả mạo/dò khóa JWT, so sánh Diff 2 gói tin và Fuzzing API.

        

        

          
          
        

      


      

        
        

          

            Vũ khí 1
            
📡 Bắt Gói Tin Webhook & Xuất File Postman

          

          
Mọi HTTP Request (GET, POST, PUT, PATCH, DELETE) gửi tới đường dẫn /hook/<slug> đều sẽ được bắt và hiển thị tức thì theo thời gian thực.

          
    
            
  • Test nhanh không cần code: Bấm các nút "💳 Thanh toán (JWT + HMAC)", "🤖 Telegram Bot" hoặc "⚠️ Payload Nghi vấn" ngay trên thanh trên cùng.
    • 
            
  • Tự động tạo Endpoint: Bắn vào bất kỳ đường dẫn nào như /hook/test-123, NetPulse sẽ tự tạo Endpoint mới cho bạn.
    • 
            
  • 📦 Xuất Postman Collection: Bấm nút "📦 Postman" ở khung bên trái để tải toàn bộ các gói tin vừa bắt được ra file chuẩn .postman_collection.json.
    • 
          

        


        
        

          

            Vũ khí 2
            
🔓 Giải Mã Tự Động (JWT, Base64, Hex & Chữ Ký HMAC)

          

          
Khi bấm chọn 1 gói tin ở danh sách bên trái, khung chi tiết bên phải cung cấp 5 công cụ phân tích chuyên sâu:

          
    
            
  • 🔍 Giải Mã & Tổng Quan: Tự động quét Header, Query và JSON Body để bung nội dung JWT (kèm kiểm tra hạn exp), Basic Auth và chuỗi Base64 ẩn.
    • 
            
  • 📦 Body & Hex Dump: Xem JSON đã căn lề đẹp song song với bảng mã Hex + ASCII (512 bytes đầu).
    • 
            
  • 🔐 Kiểm Tra Chữ Ký HMAC: Nhập Secret Key (VietQR, SePay, Casso, Stripe, GitHub, Telegram...) để đối chiếu chữ ký hoặc tính mã băm HMAC-SHA256 / SHA1 / SHA512.
    • 
            
  • 💻 Xuất Code: Chuyển gói tin thành lệnh cURL, PowerShell, Python (requests) hoặc JS (fetch) chỉ với 1 cú click.
    • 
          

        


        
        

          

            Vũ khí 3
            
🔁 Replay Studio + 📥 cURL + 🌐 Biến Môi Trường + ✅ Assertions + 🛡️ CORS

          

          
Dùng khi bạn muốn chỉnh sửa gói tin, nhập lệnh cURL từ Chrome F12, dùng biến môi trường hoặc kiểm chứng tự động:

          
    
            
  1. 📥 Dán lệnh cURL & 🌐 Biến môi trường ({{BASE_URL}}): Bóc tách lệnh Copy as cURL 1-click và định nghĩa biến dùng chung cho cả Replay lẫn Fuzzer.
    2. 
            
  2. ✅ Kiểm Chứng Tự Động (API Assertions — PASS/FAIL): Đặt điều kiện kiểm tra phản hồi (VD: status == 200, durationMs < 2000, json.success == true) để hệ thống tự chấm PASS/FAIL mỗi lần bắn.
    3. 
            
  3. 🛡️ Quét Bảo Mật & CORS + 📜 Lịch sử Replay: Chấm điểm an toàn (A–F) và ghim ⚖️ A / ⚖️ B từ lịch sử Replay sang Diff Viewer.
    4. 
          

          

            
          

        


        
        

          

            Vũ khí 4
            
⚡ Quét Lỗ Hổng & Kiểm Thử Biên (API Fuzzer)

          

          
Thử nghiệm hàng loạt dữ liệu dị biệt (số âm, tràn số, SQLi, XSS, IDOR) xem API xử lý có an toàn không:

          
    
            
  1. Từ gói tin bất kỳ, bấm "⚡ Đẩy sang Fuzzer" (hoặc mở tab API Fuzzer).
    2. 
            
  2. Đặt từ khóa {{FUZZ}} vào vị trí bạn muốn chèn payload (trên URL, trong Header, hoặc trong Body JSON, ví dụ: "amount": "{{FUZZ}}").
    3. 
            
  3. Chọn Bộ mẫu Payload có sẵn (Boundary số âm/tràn số, SQLi/NoSQLi, XSS/SSTI, hoặc dò IDOR 1..15).
    4. 
            
  4. Bấm "⚡ Chạy Fuzzing & Phân Tích Dị Thường": Hệ thống tự đo Baseline chuẩn trước, sau đó bắn đa luồng và tự động tô đỏ các dòng phản hồi bất thường.
    5. 
          

          

            
          

        


        
        

          

            Vũ khí 5
            
🕵️‍♂️ Dò API Trang Web + Bắt Sống Bằng Trình Duyệt Ngầm

          

          
Dán link trang web bất kỳ vào tab "🕵️‍♂️ Dò API Trang Web" để lấy toàn bộ API tĩnh lẫn động:

          
    
            
  1. Tích chọn "🌐 Bắt sống XHR/Fetch bằng Trình duyệt ngầm (Chrome/Edge)" rồi bấm "🔍 Quét & Lấy API" (hoặc bấm "🧪 Mẫu Demo Shop").
    2. 
            
  2. NetPulse sẽ đồng thời: (a) Mở Chrome/Edge chạy ngầm để bắt sống 100% các request XHR / Fetch thực tế kèm Header & Token thật, và (b) Tải toàn bộ file .js bundle để quét các đường dẫn /api/v1/..., fetch(), axios, OpenAPI/Swagger và biến NEXT_PUBLIC_* / VITE_*.
    3. 
            
  3. Bấm "🚀 Gọi thử" để xem phản hồi JSON ngay tại chỗ, "🔁 Replay" để nạp kèm cả Header/Token thật sang Replay, hoặc "📦 Xuất Postman (.json)"!
    4. 
          

          

            
          

        


        
        

          

            Vũ khí 6
            
🔐 JWT Studio (Chỉnh Sửa, Giả Mạo alg:none & Dò Secret)

          

          
Khi bắt được gói tin có chứa JWT, bấm "🔐 Mở trong JWT Studio" (hoặc mở tab JWT Studio):

          
    
            
  • Chỉnh sửa nhanh: Bấm "👑 role=admin" để nâng quyền trong Payload hoặc "⏰ +24h exp" để gia hạn token.
    • 
            
  • Ký mới hoặc Tấn công alg: none: Chọn ký chuẩn HMAC (HS256/384/512) hoặc tạo token không chữ ký (alg: none) để kiểm thử lỗi bỏ qua xác thực chữ ký, rồi bấm "🔁 Gắn Token Này Sang Replay Studio".
    • 
            
  • 🔥 Dò Tìm Secret Key Yếu: Bấm nút dò khóa để tự động thử hơn 30 khóa mặc định phổ biến (kèm wordlist riêng của bạn) trong vài mili-giây.
    • 
          

          

            
          

        


        
        

          

            Vũ khí 7
            
⚖️ So Sánh 2 Gói Tin (Side-by-Side Diff Viewer)

          

          
Đối chiếu sự khác biệt chi tiết giữa 2 gói tin Webhook hoặc 2 lần gọi API:

          
    
            
  1. Trong màn hình Bắt Gói Tin, bấm "⚖️ Ghim làm Gói A" ở gói thứ nhất, sau đó chọn gói thứ hai và bấm "⚖️ So sánh với A (Gói B)" (hoặc chọn trực tiếp ở tab So Sánh Gói Tin).
    2. 
            
  2. Xem ngay: Bảng chênh lệch thời gian/kích thước, Danh sách các trường JSON bị đổi giá trị, So sánh Headers/Query và Line-by-Line Body Diff (tô xanh dòng thêm mới +, tô đỏ dòng bị xóa -).
    3. 
          

          

            
          

        


        
        

          

            Vũ khí 8
            
🌍 Public Tunnel, 🔒 HMAC 401, 🔔 Cảnh Báo Telegram/Discord & 💾 Lưu Trữ Bền Vững

          

          
Nhận Webhook thật từ Internet, bắn cảnh báo tự động và lưu trữ bền vững:

          
    
            
  • 🌍 Bật Public Tunnel 1-Click: Ngay góc phải thanh Endpoint đang chọn, chọn Ngrok hoặc localhost.run (SSH miễn phí) rồi bấm "🌍 Bật Public Tunnel" để nhận link https://... công khai!
    • 
            
  • 🔒 Luật HMAC 401 & 🔔 Cảnh báo Telegram/Discord: Tự động trả về HTTP 401 khi sai chữ ký HMAC, và tự động đẩy cảnh báo về Telegram Bot / Discord Webhook khi có gói tin tới (hoặc chỉ khi phát hiện gói tin dị thường).
    • 
            
  • 💾 Lưu trữ bền vững & Xuất/Nhập Backup: Toàn bộ dữ liệu tự động lưu tại data/store.json, kèm nút "📥 Xuất Backup (.json)" / "📤 Nhập Backup".
